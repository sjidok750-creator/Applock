AppLock

설치된 앱을 4자리 PIN으로 잠그는 가장 간단한 방법

APK 다운로드 GitHub에서 보기
🔢

간단한 PIN

4자리 숫자만 외우면 끝. 추가 가입이나 계정 없이 바로 사용.

📱

앱별 잠금

설치된 앱 목록에서 토글 한 번으로 보호할 앱을 선택.

⏱️

5분 그레이스

한 번 인증하면 5분간 유지. 백그라운드로 빠지면 즉시 재잠금.

🔒

로컬 저장

PIN은 SHA-256 해시 + EncryptedSharedPreferences로 기기 내부에만 저장.

⚡

가벼움

Foreground Service 하나로 동작. 광고·트래커 0개.

🌐

오픈소스

전체 소스코드 공개. 직접 빌드해서 사용 가능.

사용 방법

  1. APK 다운로드 후 설치 출처를 알 수 없는 앱 설치 허용 필요
  2. 4자리 PIN 등록 첫 실행 시 PIN 입력 후 한 번 더 확인
  3. 두 가지 권한 허용 앱 사용 정보 접근 + 다른 앱 위에 표시
  4. 보호할 앱 토글 목록에서 잠그고 싶은 앱 옆 스위치를 켜기
  5. 끝! 이제 해당 앱을 열 때마다 PIN 입력 화면이 표시됩니다

필요한 권한

앱 사용 정보 접근
어떤 앱이 현재 화면에 있는지 감지하기 위함
다른 앱 위에 표시
잠긴 앱이 열렸을 때 PIN 입력 화면을 위에 띄우기 위함
설치된 앱 목록 조회
잠글 앱 목록을 보여주기 위함
포그라운드 서비스
백그라운드에서 지속적으로 감시하기 위함
알림: AppLock은 어떤 데이터도 외부로 전송하지 않습니다. PIN과 잠금 설정은 모두 기기에만 저장됩니다.
